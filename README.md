# Todo Application

A simple todo app where you can add, complete, and delete tasks.

## Live Demo
🔗 [Open the app](https://yasintodosapp.ccbp.tech/)

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks

## Tech Stack
- HTML, CSS, JavaScript (change to what you used)

## How to Run
1. Clone the repo:
   git clone https://github.com/yazzyasin/todo-app.git
2. Open the folder:
   cd todo-app
3. Open `index.html` in your browser
   (or run `npm install` and `npm start` if it's a Node/React app)
